Read this result carefully

    What has been validated?

    The Python reference extracted pulse on three original UBFC-rPPG videos with 5.53 BPM average error, including one 15.97 BPM miss. Those numbers do not validate this JavaScript port.

    Real/fake accuracy and fake recall are unavailable. Actual short DeepfakeTIMIT samples were inconclusive. A genuine compressed video also failed pulse quality checks. This website must not be used as a truth detector.

    Sources, privacy and scope

    This is video-only analysis: no audio, lip-sync classifier or provenance check. Five hand-weighted signal checks are not a trained deepfake model. Scores can change with compression, lighting, motion and skin appearance.

    Videos are decoded locally, never uploaded. MediaPipe JavaScript/WASM and a face model load from jsDelivr and Google storage. Those providers see ordinary asset requests, not your video. No analytics, API keys, fees or accounts.
